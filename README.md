# Mis Mangas

## Language

The app, the Apple Watch app and the widget are available in English and Spanish, and follow the
language of the system. To use a different language for Mis Mangas only, open
Settings → Apps → Mis Mangas → Language; the app has no language picker of its own.

Data that comes from the manga API (titles, synopses, authors, genres, themes and demographics)
is shown as the API provides it, in English, in both languages.
